# BOJ 1919 - 애너그램 만들기

## 1. 핵심 아이디어
- 두 문자열 각각에 대해 알파벳 등장 횟수를 26칸 배열에 기록한다.
- 같은 알파벳이라도 등장 횟수가 다르면, 그 차이만큼 문자를 삭제해야 한다.
- 모든 알파벳에 대해 등장 횟수 차이의 절댓값을 더하면 최소 삭제 횟수가 된다.

## 2. 불변식 (Invariant)
- 각 알파벳 i에 대해 `|count1[i] - count2[i]|` 는 최종적으로 두 문자열을 애너그램으로 만들기 위해 반드시 삭제해야 하는 문자 수다.

## 3. 시간 복잡도
- 시간: O(|s1| + |s2| + 26)
- 공간: O(26)

## 4. 내가 한 실수 / 주의할 점
- 애너그램 판별과 달리, 이 문제는 가능/불가능이 아니라 “삭제 횟수”를 구해야 한다는 점을 놓치기 쉽다.
- 한 문자열 기준으로만 부족한 개수를 세면 안 되고, 양쪽의 차이를 절댓값으로 계산해야 한다.
- 문자열 자체를 직접 지우면서 시뮬레이션하려 하면 비효율적이므로, 빈도 배열로 바로 계산하는 것이 핵심이다.

## 5. 복습 질문 (Active Recall)
1. 왜 각 알파벳 개수 차이의 절댓값을 모두 더하면 최소 삭제 횟수가 되는가?
2. 이 문제를 정렬로 풀 수도 있는데, 빈도 배열 풀이가 더 직관적인 이유는 무엇인가?
3. “애너그램인지 판별” 문제와 “애너그램으로 만들기 위한 삭제 수 계산” 문제의 차이는 무엇인가?
4. 빈도 배열 문제에서 `26` 크기 배열을 쓰는 이유와 장점은 무엇인가?
