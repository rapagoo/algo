# BOJ 1158 - 요세푸스 문제

## 1. 핵심 아이디어
- 1번부터 N번까지 원형으로 앉아 있다고 보고, 순서를 유지하면서 K번째 사람을 제거한다.
- `list`를 사용해 현재 위치에서 삭제 후 다음 위치로 자연스럽게 이동한다.
- 커서가 끝에 도달하면 다시 `begin()`으로 보내 원형 구조를 구현한다.

## 2. 불변식 (Invariant)
- 매 단계에서 `cursor`는 “다음으로 카운트를 진행할 현재 사람”을 가리키며, 리스트에는 아직 제거되지 않은 사람들만 순서대로 남아 있다.

## 3. 시간 복잡도
- 시간: O(NK)
- 공간: O(N)

## 4. 내가 한 실수 / 주의할 점
- `erase` 후 반환된 iterator가 `end()`일 수 있으므로 바로 순환 처리해야 한다.
- 원형 구조를 직접 만들지 않아도, `end()`일 때 `begin()`으로 되돌리면 충분하다.
- 출력 형식에서 마지막 원소 뒤에는 쉼표가 없어야 하므로 별도 처리해야 한다.

## 5. 복습 질문 (Active Recall)
1. 이 문제에서 `list`를 사용한 이유는 무엇인가?
2. `erase(cursor)`의 반환값을 바로 받아야 하는 이유는 무엇인가?
3. 선형 컨테이너로 원형 순회를 구현할 때 핵심 처리는 무엇인가?
4. 이 코드의 시간 복잡도가 O(NK)가 되는 이유는 무엇인가?
