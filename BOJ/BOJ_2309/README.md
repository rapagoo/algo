# BOJ 2309 - 일곱 난쟁이

## 1. 핵심 아이디어
- 9명 합(total)에서 “제외할 2명”을 고르면, 남은 합이 100인지 확인한다.
- (i, j) 두 명을 완전탐색으로 선택하고 total - (dwarf[i]+dwarf[j]) == 100이면 정답.
- 정답 7명을 출력하기 위해 두 명을 0으로 바꾸고 정렬 후 0 두 개를 제외하고 출력한다.

## 2. 불변식 (Invariant)
- 어떤 (i, j)를 선택했을 때 `total - (dwarf[i] + dwarf[j])`는 “나머지 7명의 합”이다.

## 3. 시간 복잡도
- 시간: O(9^2 + 9log9) ? O(1)
- 공간: O(1)

## 4. 내가 한 실수 / 주의할 점
- 찾자마자 `return 0;`으로 종료하지 않으면 중복 출력 가능.
- 0으로 바꾸는 방식은 입력에 0이 없다는 전제에 의존(이 문제는 키가 자연수라 안전).
- 출력은 오름차순 요구이므로 정렬을 반드시 수행.

## 5. 복습 질문 (Active Recall)
1. 왜 2명을 고르는 완전탐색이 충분한가?
2. `total - (dwarf[i]+dwarf[j])`가 의미하는 값은 무엇인가?
3. 두 명을 0으로 바꾸고 정렬하면 왜 0 두 개가 앞에 오나?
4. 정답을 찾은 뒤 즉시 종료해야 하는 이유는?
