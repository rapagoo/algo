# BOJ 2178 - 미로 탐색

## 1. 핵심 아이디어
- 시작점 (0,0)에서 BFS를 수행하면, 먼저 도달하는 경로가 항상 최단 경로이다.
- 이동 가능한 칸('1')만 큐에 넣고, 이미 방문한 칸은 dist 배열로 중복 방문을 막는다.
- dist[x][y]를 "시작점으로부터 해당 칸까지 이동한 간선 수"로 두고, 마지막에 시작칸 포함을 위해 +1 한다.

## 2. 불변식 (Invariant)
- 큐에 들어가는 모든 칸은 시작점에서 해당 칸까지의 최단 거리(dist)가 이미 확정된 상태이다.

## 3. 시간 복잡도
- 시간: O(NM)
- 공간: O(NM)

## 4. 내가 한 실수 / 주의할 점
- dist를 방문 배열 겸 거리 배열로 사용할 때, 초기값(-1)의 의미를 명확히 잡아야 한다.
- 시작칸을 dist=0으로 둘지 dist=1로 둘지 먼저 정하지 않으면 마지막 출력에서 +1 여부를 헷갈리기 쉽다.
- board를 string으로 받을 때 board[x][y]는 문자이므로 반드시 '1'처럼 문자 비교를 해야 한다.

## 5. 복습 질문 (Active Recall)
1. 왜 BFS는 미로 탐색에서 최단 경로를 보장하는가?
2. dist 배열을 방문 배열 대신 함께 사용할 때 초기값을 -1로 두는 이유는 무엇인가?
3. 이 코드에서 dist[n-1][m-1]에 마지막으로 +1을 해주는 이유는 무엇인가?
4. 시작칸의 dist를 1로 두는 방식과 0으로 두는 방식의 차이는 무엇인가?
