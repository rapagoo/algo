# BOJ 10804 - 카드 역배치

## 1. 핵심 아이디어
- 1부터 20까지의 카드를 벡터에 순서대로 저장한다.
- 입력으로 주어진 [start, end] 구간을 `reverse`로 그대로 뒤집는다.
- 총 10번의 구간 뒤집기를 순서대로 적용한 뒤 최종 배열을 출력한다.

## 2. 불변식 (Invariant)
- 각 연산이 끝난 뒤에도 카드의 개수와 카드 값 집합(1~20)은 유지되며, 오직 지정된 구간 내부의 상대적 순서만 뒤집힌다.

## 3. 시간 복잡도
- 시간: O(10 × 20) = O(1)
- 공간: O(20) = O(1)

## 4. 내가 한 실수 / 주의할 점
- 입력은 1-based 인덱스인데, 벡터는 0-based라서 `start - 1` 보정이 필요하다.
- `reverse`의 두 번째 인자는 포함 끝이 아니라 “바로 다음 위치”라서 `v.begin() + end`로 써야 한다.
- 문제를 직접 swap으로 구현하려다가 인덱스 실수가 날 수 있는데, STL `reverse`를 쓰면 더 안전하다.

## 5. 복습 질문 (Active Recall)
1. 이 문제에서 `reverse(v.begin() + start - 1, v.begin() + end)`가 되는 이유는 무엇인가?
2. 왜 `end - 1`이 아니라 `end`를 두 번째 인자로 넣어야 하는가?
3. 각 연산 이후에도 반드시 유지되는 불변식은 무엇인가?
4. 이 문제를 직접 swap으로 구현한다면 어떤 인덱스 실수가 가장 자주 발생하는가?
