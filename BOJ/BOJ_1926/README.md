# BOJ 1926 - 그림

## 1. 핵심 아이디어
- 전체 격자를 순회하면서 아직 방문하지 않은 1을 시작점으로 잡는다.
- 시작점마다 BFS를 수행해 연결된 하나의 그림 넓이를 계산한다.
- BFS가 끝날 때마다 그림 개수와 최대 넓이를 갱신한다.

## 2. 불변식 (Invariant)
- 큐에 들어있는 모든 칸은 같은 그림에 속하며, `vis=true`인 1 칸은 이미 어떤 그림에 소속되었거나 현재 BFS로 확장 중이다.

## 3. 시간 복잡도
- 시간: O(NM)
- 공간: O(NM)

## 4. 내가 한 실수 / 주의할 점
- BFS 시작 직후 `vis[i][j] = true`를 먼저 처리하지 않으면 중복 방문이 발생할 수 있다.
- 넓이(`area`)는 큐에 넣는 시점이 아니라 실제로 꺼내는 시점 기준으로 1씩 증가시키는 흐름을 끝까지 일관되게 유지해야 한다.
- 그림이 하나도 없는 경우 최대 넓이는 0이 출력되어야 하므로 초기값 처리를 자연스럽게 가져가야 한다.

## 5. 복습 질문 (Active Recall)
1. 이 문제에서 “그림의 개수”와 “가장 넓은 그림의 넓이”는 각각 언제 갱신해야 하는가?
2. BFS를 시작할 수 있는 좌표의 조건은 무엇인가?
3. `vis` 배열이 없다면 어떤 중복/오답 문제가 생기는가?
4. 왜 이 문제의 전체 시간 복잡도는 O(NM)인가?
