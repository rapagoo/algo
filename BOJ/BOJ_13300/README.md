# BOJ 13300 - 방 배정

## 1. 핵심 아이디어
- 성별(여/남)과 학년(1~6) 조합별로 학생 수를 센다.
- 각 조합은 서로 다른 방에 배정되어야 하므로, 조합별 인원을 독립적으로 처리한다.
- 각 조합의 학생 수를 방 정원 K로 나눈 뒤 올림 처리해서 필요한 방 개수를 구한다.

## 2. 불변식 (Invariant)
- `students[성별][학년]`에는 해당 성별·학년에 속한 학생 수가 정확히 누적되어 있다.

## 3. 시간 복잡도
- 시간: O(N)
- 공간: O(1)

## 4. 내가 한 실수 / 주의할 점
- 문제 조건상 성별과 학년이 둘 다 같아야 같은 방에 들어갈 수 있는데, 둘 중 하나만 기준으로 묶으면 틀린다.
- 방 개수 계산에서 나눗셈 몫만 쓰면 부족한 인원이 있는 경우를 놓친다. 반드시 올림 처리가 필요하다.
- 학년이 1부터 시작하므로 인덱스를 다룰 때 `0~6` 중 `0`은 사실상 비어 있다는 점을 의식해야 한다.

3. 성별과 학년을 각각 따로 세면 안 되고, 반드시 2차원 기준으로 세야 하는 이유는 무엇인가?
