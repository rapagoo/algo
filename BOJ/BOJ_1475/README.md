# BOJ 1475 - 방 번호

## 1. 핵심 아이디어
- 각 숫자의 등장 횟수를 센다.
- 숫자 6은 9와 서로 대체 가능하므로, 6을 모두 9로 합쳐서 계산한다.
- 최종적으로 9의 개수를 `(개수 + 1) / 2`로 처리한 뒤, 가장 많이 필요한 숫자의 개수가 곧 필요한 세트 수가 된다.

## 2. 불변식 (Invariant)
- 숫자 6과 9를 제외한 각 숫자는 자신의 등장 횟수만큼 세트가 필요하고, 6과 9는 합친 총 개수를 2개씩 나눠 세트 수를 계산한다.

## 3. 시간 복잡도
- 시간: O(N)
- 공간: O(1)

## 4. 내가 한 실수 / 주의할 점
- 6과 9를 따로 세면 불필요하게 많은 세트 수가 계산될 수 있다.
- 6과 9의 합을 처리할 때 올림 나눗셈이 필요하다는 점을 놓치기 쉽다.
- 정답은 숫자별 개수의 합이 아니라, 가장 많이 필요한 숫자의 최대 빈도라는 점을 잊지 말아야 한다.

## 5. 복습 질문 (Active Recall)
1. 왜 6과 9는 같은 그룹으로 묶어서 계산해야 하는가?
2. 6과 9의 총 개수를 처리할 때 왜 `(x + 1) / 2`를 사용하는가?
3. 최종 정답이 각 숫자 개수의 합이 아니라 최댓값인 이유는 무엇인가?
4. 이 문제에서 배열 크기를 10으로 두는 이유와 각 인덱스의 의미는 무엇인가?
