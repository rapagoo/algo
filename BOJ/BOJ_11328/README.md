# BOJ 11328 - Strfry

## 1. 핵심 아이디어
- 두 문자열이 서로 애너그램 관계인지 확인하면 된다.
- 각 문자열의 알파벳 등장 횟수를 26칸 배열에 저장한다.
- 두 빈도 배열이 완전히 같으면 재배열로 만들 수 있으므로 Possible이다.

## 2. 불변식 (Invariant)
- 두 문자열이 서로 strfry 관계이려면, 모든 알파벳에 대해 각 문자 등장 횟수가 정확히 같아야 한다.

## 3. 시간 복잡도
- 시간: O(T * L)
- 공간: O(1)

## 4. 내가 한 실수 / 주의할 점
- 문자열 자체의 순서가 아니라 “문자별 개수”가 같은지를 봐야 한다.
- 테스트케이스마다 빈도 배열을 반드시 새로 초기화해야 한다.
- 길이가 같아 보여도 특정 알파벳 개수가 다르면 Impossible이다.

## 5. 복습 질문 (Active Recall)
1. 이 문제에서 문자열 정렬 없이도 비교할 수 있는 이유는 무엇인가?
2. 두 문자열이 strfry 관계라는 것을 배열 기준으로 어떻게 정의할 수 있는가?
3. 왜 알파벳 소문자만 나오면 크기 26 배열로 충분한가?
4. 빈도 배열 비교 방식의 시간 복잡도는 왜 O(L)인가?
